# 案例：克劳德娘（一次完整的实战）

记录这个形象的**全部实测数字**，方便对照 —— 你的角色不会是这些数，但**量的顺序和用途**是一样的。

---

## 0. 需求与约束

- 目标：把 Coopanion 桌面上的形象换成一只 Q 版 Claude 娘（橙发、雏菊、蕾丝衬衫、黑束腰、奶白蛋糕裙）
- 硬要求：动画流畅、表情自然、最终要**替换当前形象**
- 参考：B 站「Claude 娘」二创的四张图（正面全身 2 张、脸部 1 张、立绘 1 张）
- 生图：图生图（一张画风模板 + 两张角色设定）

---

## 1. 生图

- 尺寸 `928×1664`，一次出 2 张，取第 2 张
- 输入：`style-base.png`（上一版银发立绘，按 928×1664 白底补齐，`scale=928:1392 + pad 136`）+ `design-upper.png` + `design-chibi.png`
- 产出 2 张里，第 1 张左手手指略歪、表情更呆；第 2 张选为定稿
- 提示词的骨架：**第 1 张锁结构（二头身/正面/粗描边/平涂/纯白底/整身），第 2、3 张给设计（发型、瞳色、发饰、服装）**

## 3. 五官矢量化

先抹掉贴图上的眼睛/眉/嘴，再用 SVG 画。抹除参数：

- `P = { face:{275,284,551,492}, eyeL:{322,369,46,49}, eyeR:{505,369,46,49}, browY:318, mouth:{403,451,9,5}, skin:[252,232,212] }`
- 掩码 = 眼形超椭圆（`rx+4 / ry+4`）∪ 眉毛带（`|x-cx|≤10`，且"上方 7 px 是皮肤"）
- 填充 = 同行皮肤锚点插值 与 逐行肤色中位数 各 50%，羽化 3 px，绕开头发掩码

配色（从贴图上量的，不是拍的脑袋）：

| 用途 | 值 |
|---|---|
| 眼线 / 睫毛 | `#0d0300` |
| 巩膜 | `#fffaf3` |
| 虹膜暗 / 主 / 亮 | `#7a3a12` / `#e0722a` / `#f7ad46` |
| 瞳孔 | `#3d1f0e` |
| 上眼皮 / 下眼皮（渐变） | `#fde3cf` → `#ffcfb4` |
| 嘴 | `#b06a4e` |

眼睛几何（在 kit 的 16 基准下）：

```
kx = 8.6/16 = 0.5375, ky = 9.2/16 = 0.575
ox = rx*0.95, oy = ry*0.70          眼开口（超椭圆裁切）
cyE = cy + ry*0.21                  虹膜中心略下移
irx = min(ox*1.02, rx*0.84)         虹膜 0.85 倍宽
iry = min(oy*0.88, ry*0.72)         虹膜 0.72 倍高 → 下方留月牙眼白
lashT = clamp(ry*0.24, 1.7, 3.6)    上眼线厚度
下面眼线：22°/56°/90°/124°/158° 五点两段曲线，clamp(sw*0.26, .4, .85)
```

## 4. rig 结构

```
deformers:
  legs  warp  rect [40,196,220,256]   parent root
  skirt warp  rect [36,140,222,236]   parent legs
  hair  warp  rect [26,52,232,244]    parent skirt
parts:
  body  tex 'body'  box = parts[0]  grid [84,150]  z 5  parent hair
```

一次实际的参数演进（写在这里是因为它是可复用的"手感"）：

| 参数 | 一开始 | 改成 | 为什么 |
|---|---|---|---|
| 腿 | 绕髋旋转 ±20° | 纯平移 `dx*0.52` + 抬脚 `lift*0.50` | 旋转会把鞋子拧成风车 |
| 头发甩动 | `-sway*1.9` | 先乘再 clamp | 幅度过大甩出鼓包 |
| 整体变换 | rig `root` | 父 `<g>` 的 `transform` | 否则五官不跟（见 PITFALLS #3） |
| 虹膜高度 | `0.90*ry` | `0.72*ry` | 原画下方有月牙眼白 |
| 嘴阈值 | `(gap-43)/20` | `(gap-54)/12` | 否则呼吸就变圆「o」 |

## 7. 这次妥协的地方（也都是你的可选菜单）

1. **手臂不会动**。原画的手是垂在身侧的固定姿势，走路时只有腿和裙摆动。要做挥手动，得让生图模型补一套手臂素材。
2. **没有眉毛**。原画眉毛藏在刘海下，画上去反而像贴片，所以常态不画；只有 kit 给出 `brows`（生气/难过）时才画。
3. **`shy / smug / thinking / sleepy` 四个表情彼此偏像**。都是"半瞑眼 + 小嘴"，差别只在眉眼细节；二头身能表现的空间确实有限。
4. **泪滴/汗滴是 kit 自己画的**，比原画风格艳一点，属于宿主行为，包这边改不了。
